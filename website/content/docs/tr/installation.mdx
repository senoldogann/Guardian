## Sistem gereksinimleri

- macOS 13+
- Windows 10+
- İnternet bağlantısı (release kontrolü için)

## Kurulum adımları

1. İndirme sayfasından önerilen paketi seçin.
2. Paketi çalıştırın ve standart kurulum adımlarını tamamlayın.
3. Uygulamayı açıp provider yapılandırmasını yapın.

## Doğrulama

- Uygulama açıldıktan sonra Ayarlar > Updates bölümünde mevcut sürüm görünmelidir.
- İlk tarama başarılı şekilde başlatılabilmelidir.
