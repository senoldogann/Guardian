## GitHub login tamamlanmıyor

- Doğrulama sayfasında işlem tamamlandıktan sonra uygulamaya geri dönün.
- Gerekirse yeniden deneme butonunu kullanın.

## Updates bölümünde sürüm görünmüyor

- Distribution release içinde `latest.json` varlığını kontrol edin.
- `latest.json` URL’lerinin public distribution repo’yu gösterdiğini doğrulayın.

## İndirilen paket yanlış platform

- Download sayfasında manuel paket listesinden doğru artefact’ı seçin.
- Platform algılamasında tarayıcı eklentileri etkisi varsa gizli pencerede test edin.
