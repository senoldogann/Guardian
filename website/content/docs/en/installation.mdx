## System requirements

- macOS 13+
- Windows 10+
- Internet connection for release checks

## Installation steps

1. Use the Download page and choose the recommended installer.
2. Run the package and complete default install steps.
3. Launch the app and configure providers.

## Verification

- In Settings > Updates, the current version should be visible.
- A first scan should start successfully.
