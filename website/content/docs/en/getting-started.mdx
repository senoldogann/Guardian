## What is Guardian?

Guardian is a desktop governance app that evaluates codebases against architecture constraints, security expectations, and release quality standards.

## Who is it for?

- Technical leads
- Platform and DevOps teams
- Security and quality owners

## How it works

1. Scans the codebase and classifies findings.
2. Prioritizes issues by severity.
3. Connects with release flows to deliver updates inside the app.

## First 10 minutes

- Install the application.
- Configure provider settings.
- Start your first scan.
- Prioritize findings.
