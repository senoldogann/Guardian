## GitHub login does not complete

- Return to the app after finishing on the verification page.
- Use retry if needed.

## Version is missing in Updates tab

- Confirm `latest.json` exists in the distribution release.
- Verify all URLs in `latest.json` point to the public distribution repo.

## Wrong package is recommended

- Use the manual package list on Download page.
- If detection looks incorrect, test in a clean browser profile.
