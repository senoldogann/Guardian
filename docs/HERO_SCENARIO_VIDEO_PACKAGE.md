# Hero Scenario Video Package (Phase 2)

## Goal

Single hero scenario for landing page:

> Developer used Copilot/Claude/Cursor to create a large PR. Guardian flags architectural drift, explains risk, suggests a fix, and requires human approval before release.

## 60s Script

1. **0-8s (Problem):** “AI generated a huge refactor. Team velocity is up, release confidence is down.”
2. **8-20s (Intake):** Show Guardian detecting `ai_heavy_change` and policy packs.
3. **20-35s (Policy):** Show critical + warning findings and risk explanation panel.
4. **35-50s (Approval):** Show `BLOCK_UNTIL_APPROVED`, then human approver + override reason flow.
5. **50-60s (Outcome):** “Control AI-generated code before it ships.”

## Storyboard

- Scene 1: Large PR opened from AI assistant output.
- Scene 2: Guardian monitor highlights architecture/security drift.
- Scene 3: Guru explains why change is risky and proposes safe fix.
- Scene 4: Release Decision panel shows block, approver decision, audit trail line.
- Scene 5: Final release gate turns green with policy-backed confidence.

## CTA Mapping

- Primary CTA: **Download Guardian**
- Secondary CTA: **Read Docs**
- Supporting CTA: **See Release Workflow**
